# PORTION A-03a — services: FlowService.add_minutes

Goal: One method. C3.3 specifies:

    add_minutes(project_code, held_at, attendees, decisions,
                agreed_actions, risks, minutes_text, cycle_id=None)
                -> MinutesRow

Delegate to kit.minutes.add, which takes the same eight arguments in the same
order and returns an int id. Fetch the row for that id and return it.

times as a single card because list_for_project aggregates seven repositories
and add_minutes was competing with it for attention. list_for_project is
A-03b's only job.

  slots. Do not open any .py file under data/.

Done when:
  - add_minutes exists on FlowService with the EXACT C3.3 signature,
    asserted by inspect.signature against the contract transcribed into the
    test.
