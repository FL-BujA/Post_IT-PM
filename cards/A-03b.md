query the UI needs, and it is this card's only job.

C3.3 specifies the contents verbatim:

    list_for_project(project_code) -> ProjectSnapshot
      snapshot = project + current cycle + that cycle's actions (priority asc)
      + open gates + last 20 events (desc) + last 5 minutes + last 10 signals

ProjectSnapshot does not exist. This card defines it as a frozen dataclass in
services/flow.py. Every element is a C2 row already in core.sig.txt — this
card introduces no new row type.

  project        kit.projects.get(project_code)          -> ProjectRow

  actions        kit.actions.list_for(project_code, cycle_id=<current>)
  open_gates     kit.gates.list_for(project_code), filtered to open
  events         kit.events.list_for(project_code, limit=20)
  minutes        kit.minutes.list_for(project_code)
  signals        kit.signals.list_for(project_code)
